# 紙彩 Paperhue — ULANI 永恆曆（ULANI e-paper calendar）的免費 Windows 程式

[English](README.md) | 繁體中文

**紙彩（Paperhue）** 是免費、開放原始碼的 Windows 程式，可以把你自己的照片、行事曆與待辦事項放到
**ULANI 七色電子紙裝置**上。最多可以選四張照片，先看它們在七色電子紙上的效果，
再透過藍牙傳到裝置；任何一頁也可以改成月曆、一週行程或待辦清單，內容來自你自己行事曆的
iCal 網址，可手動或每天定時更新。不需要帳號、不用登入，中間也不經過任何雲端服務。

![紙彩的 Windows 視窗：四張照片已推送到裝置](docs/img/windows-app.png)

## 功能

裝置可以存四頁畫面，用按鍵切換。每一頁可以放：

- **照片**：紙彩把你選的照片縮放成 800 × 480、轉換成面板的七種顏色，
  再透過藍牙（Bluetooth LE）傳到你指定的那一頁。紙彩的預覽只用這七種顏色呈現，傳送前就能看出效果；實際電子紙上的顏色會比螢幕柔和一些。
- **行事曆頁**：「月曆」「一週行程」或「待辦清單」，內容來自你的行事曆（見[行事曆與待辦頁](#行事曆與待辦頁)）。

## 下載

**[下載 Paperhue.exe](https://github.com/markhhm/ulani-epaper/releases/latest/download/Paperhue.exe)**（最新版）

- Windows 10 或 11，電腦需要支援藍牙低功耗（Bluetooth LE）。大部分筆電都有內建；桌上型電腦可能要另外接藍牙 4.0 以上的 USB 接收器。
- 只有一個檔案，不需要安裝：存到任何地方，按兩下就能開啟。

## 第一次使用

### 1. 讓 Windows 開啟紙彩

下載時瀏覽器可能會先提示這個檔案不常被下載，請選「**保留**」（Edge 要先按下載項目旁的「…」）。

Paperhue.exe 沒有數位簽章，第一次開啟時 Windows 可能會顯示「**Windows 已保護您的電腦**」。
請按「**其他資訊**」，再按「**仍要執行**」。

### 2. 將裝置與電腦配對（只需一次）

裝置只會和配對過的電腦連線。

1. 長按裝置按鍵約 5 秒，直到 LED 綠燈閃爍（配對模式）。
2. 在電腦上開啟「**設定 → 藍牙與裝置 → 新增裝置 → 藍牙**」（Windows 10：「**設定 → 裝置 → 新增藍牙或其他裝置 → 藍牙**」），選擇名稱以 **ULANI Calendar** 開頭的裝置。
   Windows 11 若清單裡找不到裝置，請到「**設定 → 藍牙與裝置 → 裝置**」，把「**藍牙裝置探索**」設為「**進階**」，再讓裝置重新進入配對模式後重試。
3. 開啟紙彩，按「**讀取狀態**」。上方的「裝置狀態」出現電量和目前顯示的頁數，就代表可以開始使用了。

其他也和裝置配對過的手機或電腦，同樣可以改寫裝置上的頁面；如果不再在那台手機或電腦上使用它，請在那台手機或電腦上移除配對。

## 把照片放到裝置上

1. 在每一頁（「**第 1 頁**」到「**第 4 頁**」）按「**選擇照片…**」或點預覽區，選一張照片。
   支援 JPG、PNG、BMP、GIF、WebP、TIFF；HEIC 請先轉成 JPG。
   沒有選照片的頁面，裝置上會維持原樣。按「**清除**」可以取消那一頁選的照片（不會清掉裝置上的畫面）。
   每一頁上方的「**顯示**」選單決定這頁放什麼：「照片」或行事曆頁。照片只會放在設為「照片」的頁面；
   預設只有第 4 頁是照片（第 1–3 頁是行事曆頁），要放照片的頁面請先改成「照片」。
2. 在頁面上方選擇選項（所有照片頁共用）：
   - 「**填滿畫面（裁切多餘部分）**」：照片填滿 5:3 的畫面，這是預設選項。
   - 「**完整顯示（留白邊）**」：整張照片都放進畫面，多出的地方留白。
   - 「**顆粒感**」：用七種顏色交錯出細緻色調的程度。「**標準**」（預設）細節最多；
     「**柔和**」「**更柔和**」「**最平滑**」顆粒較少、畫面較平靜，但色帶會比較明顯。

   幾秒後預覽就會更新成七色效果，下方顯示「預覽為裝置實際顯示的 7 色效果」（顯示「產生預覽中…」時請稍候）；所有預覽完成後才能按「**推送照片到裝置**」。
3. 按「**推送照片到裝置**」，每一頁會各自顯示進度。

裝置上正在顯示的那一頁會最後傳，所以面板只會刷新一次。每頁通常約 25–30 秒（藍牙較慢時可能到 50 秒左右），
四頁全部大約 2 分鐘；裝置上已經是同一張照片的頁面會自動略過。下方出現「**完成**」之前，請不要關閉紙彩；
之後裝置還需要約 40 秒刷新畫面。其他頁面一樣存在裝置裡，按裝置按鍵就能切換過去。
傳送中關閉紙彩會中斷推送，之後再推送一次即可。

**小技巧：** 把最多四張照片拖到 **Paperhue.exe** 的檔案圖示上（不是已開啟的視窗），紙彩開啟時會把它們放在照片頁；照片比照片頁多時，會問你要不要把行事曆頁改成照片。順序由 Windows 決定，推送前請確認每一頁。

## 行事曆與待辦頁

任何一頁都可以顯示你自己的行事曆，風格像手機的小工具：

| 月曆 | 一週行程 | 待辦清單 |
|---|---|---|
| ![月曆頁](shared/layouts/agenda/golden/month_sample.png) | ![一週行程頁](shared/layouts/agenda/golden/agenda_sample.png) | ![待辦清單頁](shared/layouts/agenda/golden/todo_sample.png) |

內容來自你的行事曆的 **iCal（.ics）網址**：Google 日曆的「iCal 格式的私密網址」、Outlook 發佈的行事曆、
Nextcloud 待辦清單等。紙彩只是下載這些網址，跟訂閱行事曆一樣：不用 Google 或其他公司的 API、不用建立雲端專案、不用授權登入。

1. 按「**行事曆來源…**」→「**新增…**」，填名稱（顯示在頁面上，例如「個人」）、貼上網址、選顏色，
   再按「**檢查並儲存**」。紙彩會先下載一次，並告訴你近期有幾個行程、幾項待辦。
2. 把各頁的「**顯示**」選單設成「月曆」「一週行程」或「待辦清單」。
3. 按「**立即同步**」；或按「**每日排程…**」，讓 Windows 每天定時更新（預設 06:00、12:00、18:00，電腦需開機並登入）。

內容沒變的頁面會自動略過，面板不會白白重刷。各家行事曆的網址在哪裡、哪些待辦服務可以用、來源失效時怎麼處理，
見 [docs/CALENDARS.md](docs/CALENDARS.md)。

## 疑難排解

出問題時，紙彩會跳出「推送失敗」「同步失敗」或「讀取狀態失敗」視窗；第一行是中文說明，下方是英文的技術細節。請依第一行開頭對照下表（照片無法開啟時，則會在那一頁下方顯示「無法讀取 …」）：

| 訊息 | 處理方式 |
|---|---|
| 裝置尚未與這台電腦配對 | 依上面的步驟配對裝置。 |
| 找不到裝置或連不上 | 把裝置拿近電腦，確認電腦藍牙已開啟、裝置已與這台電腦配對，而且現在沒有其他手機或電腦連著裝置，再推送一次。 |
| 裝置沒有回應 | 裝置可能還在刷新畫面（約 40 秒）。等一分鐘後再推送一次。 |
| 裝置回報收到的資料有誤 | 再推送一次。 |
| 藍牙連線中斷 | 把電腦靠近裝置，再推送一次。 |
| 無法讀取 … | 檔案損壞、圖片太大，或是紙彩無法開啟的格式（HEIC 請先轉成 JPG）。 |
| 還沒有行事曆來源 | 按「行事曆來源…」加入 iCal 網址。 |
| 無法讀取行事曆來源 | 確認網路連線；如果來源的網址被重設了，到「行事曆來源…」→「編輯…」貼上新網址。下方細節會寫出是哪個來源、哪個 HTTP 錯誤。 |

其他建議：

- 裝置為了省電，只會偶爾發出藍牙訊號。紙彩會自動重試，最久約兩分鐘才會放棄，所以「連線中…」可能會停留一陣子。如果還是連不上，再試一次就好。
- 推送到一半中斷時，直接再推送一次：已經是同一張照片的頁面會自動略過。
- 推送後裝置顯示的是別頁，按裝置按鍵切換到想看的那一頁即可。
- 如果裝置跟其他手機或電腦配對過後，這台電腦就連不上了，請到 Windows 的藍牙設定移除裝置，再重新配對。

還是無法解決？請到 [GitHub Issues](https://github.com/markhhm/ulani-epaper/issues) 回報，並附上紙彩顯示的訊息。

## 隱私

紙彩不需要帳號，也不使用任何雲端服務。除了透過藍牙傳到你自己的裝置，你的照片不會離開你的電腦。

唯一的網路連線是下載你加入的行事曆網址。網址就像密碼，所以紙彩把它存在 Windows 認證管理員（不是一般檔案），
畫面上只顯示主機名稱（例如 calendar.google.com）。行程與待辦只在記憶體中下載、繪製、傳到裝置，
不會存在電腦上；同步紀錄只記時間、結果，以及有幾個行程、幾項待辦。

## 給開發者

紙彩建立在小型 Python 函式庫 `ulani-epaper` 之上，你也可以在自己的程式裡使用它（Python 3.10–3.14）：

```
pip install "ulani-epaper @ git+https://github.com/markhhm/ulani-epaper#subdirectory=python"
```

```python
import asyncio
from ulani_epaper.push import push_images

# 第 n 張照片放到第 n 頁；None 代表那一頁不動
asyncio.run(push_images(["a.jpg", "b.jpg", None, "d.jpg"]))
```

安裝後也會有 `ulani` 命令列工具（`ulani push`、`ulani send`、`ulani text`、`ulani info` 等）。
行事曆頁（`ulani feeds`、`ulani sync`、`ulani schedule`）需要 `calendar` 額外套件：
`pip install "ulani-epaper[calendar] @ git+https://github.com/markhhm/ulani-epaper#subdirectory=python"`。
API、命令列工具、測試與自行建置 Paperhue.exe 的方式見 [python/README.md](python/README.md)（英文）；
藍牙協定見 [shared/PROTOCOL.md](shared/PROTOCOL.md)（英文）。

| 資料夾 | 內容 |
